## Bienvenue sur le projet LesPetitsPlats ! 👋
Le projet **LesPetitsPlats** consiste à développer une application de recherche de recettes 100% JavaScript natif. L'objectif est de proposer une interface fluide qui permet aux utilisateurs de rechercher des recettes via une barre de recherche principale et une sélection de tags dynamiques (ingrédients, appareils, ustensiles). L'expérience est pensée pour être intuitive et rapide.

## 🏗️ Exigences et Consignes Techniques
- L'application est structurée en **modules JavaScript** avec une séparation claire entre gestion d’objet de donnée (`data/`), la logique métier (`service/`), l'affichage (`view/`) et les composants (`components/`).
- L’algorithme de recherche doit être rapide, optimisé et le plus fluide possible.

---

## 👷 Missions principales

1. 🧱 **Système de recherche avancée** :
   - Barre de recherche principale avec saisie libre.
   - Prise en charge des caractères spéciaux, espaces, etc.

2. 🧱 **Filtrage par tags** :
   - Systèmes de tags dynamiques (ajout/suppression).
   - Recherche combinée (textuelle + tags).

3. 🧱 **Affichage des résultats** :
   - Cartes recettes dynamiques générées en JS.
   - Gestion des états : aucun résultat, compteur, etc.

4. 🧱 **Architecture modulaire** :
   - Code organisé en modules (Single Responsibility).
   - Utilisation du **pattern Singleton** pour la gestion des données.

---

## 🕵️ Stratégie

1. 🧱 Analyse de l’API des recettes.
2. 🧱 Implémentation de la recherche principale.
3. 🧱 Construction des composants dynamiques (cartes, tags...).
4. 🧱 Mise à jour du DOM sans rechargement.
5. 🧱 Gestion des erreurs, messages d’état.
6. 🧱 Séparation claire entre services, vues et données.
7. 🧱 Test manuel des modules.
8. 🧱 Nettoyage du code + commentaires + JSDoc.
